# 과제 제출 폴더

**제출 방법과 채점 기준은 [docs/05-assignment-submission.md](../docs/05-assignment-submission.md) 에 있습니다.**
이 파일은 폴더 구조와 시작 절차만 다룹니다.

---

## 1. 내 폴더 만들기 (학기 초 한 번)

```
assignments/
├─ README.md              ← 이 파일 (수정 금지)
├─ _TEMPLATE/             ← 복사해서 쓰는 원본 (수정 금지)
└─ 32251234_홍길동/        ← 본인 폴더. 여기 안에서만 작업
   ├─ hw1/
   └─ hw2/
```

**절차**

1. `main` 브랜치에서 **Pull** (최신화)
2. 브랜치 생성: `hw1/32251234-홍길동`
3. `_TEMPLATE` 폴더를 복사해 `32251234_홍길동/hw1/` 로 이름 변경
4. `hw1/README.md` 의 학번·이름을 본인 것으로 수정
5. 코드 작성 → commit → Publish Branch → Pull Request

## 2. 폴더·파일 이름 규칙

| 대상 | 형식 | 예 |
| --- | --- | --- |
| 학생 폴더 | `학번_이름` | `32251234_홍길동` |
| 과제 폴더 | `hw` + 숫자 | `hw1`, `hw2` |
| 코드 파일 | 영문 소문자 + `_` | `hw1.py`, `newmark_solver.py` |
| 그림 | `figs/` 하위 PNG | `figs/response.png` |
| 브랜치 | `hwN/학번-이름` | `hw1/32251234-홍길동` |
| PR 제목 | `[HWN] 학번 이름` | `[HW1] 32251234 홍길동` |

> 파일명에 **한글·공백·특수문자를 쓰지 마세요.** 다른 OS에서 열리지 않거나 깨집니다.
> 폴더명의 한글 이름은 채점 편의를 위해 예외로 허용합니다.

## 3. 해서는 안 되는 것

| 금지 | 결과 |
| --- | --- |
| 다른 사람 폴더 수정 | -10점, 충돌 유발 |
| `docs/`, `examples/` 수정 | -10점 (오탈자 제보는 Issues로) |
| `main`에 직접 push | -10점 |
| Commit만 하고 Push 안 함 | **미제출 처리** |
| 100 MB 넘는 파일 커밋 | push 자체가 거부됨 |

## 4. 제출 전 마지막 확인

- [ ] VS Code를 재시작한 상태에서 `python hwN.py` 가 한 번에 실행된다
- [ ] 출력 숫자가 README에 적은 값과 일치한다
- [ ] `figs/` 에 그림이 실제로 저장되어 있다
- [ ] **브라우저에서 내 브랜치를 열어 파일이 다 보인다** (= push 완료)
- [ ] PR 제목이 `[HWN] 학번 이름` 형식이다
- [ ] README에 **AI 사용 내역**이 적혀 있다
