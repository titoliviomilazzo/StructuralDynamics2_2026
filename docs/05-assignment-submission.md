# 05 — 과제 제출 규칙

**제출 = Pull Request.** 메일·카톡·USB 제출은 받지 않습니다.
제출 시각은 **PR 생성 시각**이 아니라 **마지막 커밋 시각**으로 기록됩니다.

---

## 1. 폴더·파일 규칙

```
assignments/
└─ 32251234_홍길동/          ← 학번_이름 (언더스코어 하나, 공백 없음)
   ├─ hw1/
   │   ├─ hw1.py             ← 실행 가능한 코드
   │   ├─ README.md          ← 결과 정리 (아래 양식)
   │   └─ figs/
   │       └─ response.png   ← 그래프
   └─ hw2/
```

| 항목 | 규칙 | 이유 |
| --- | --- | --- |
| 폴더명 | `학번_이름` | 채점 자동 분류 |
| 파일명 | 영문 소문자 + 숫자 + `_` | 한글·공백 파일명은 다른 OS에서 깨짐 |
| 인코딩 | UTF-8 (VS Code 기본) | 한글 주석 깨짐 방지 |
| 그래프 | `figs/` 에 PNG | 코드가 그림을 저장하도록 짤 것 |

### 올리면 안 되는 것
- 100 MB 넘는 파일 (GitHub이 거부합니다)
- 해석 프로그램 원본 결과 바이너리
- 개인정보·비밀번호·API 키
- `__pycache__/`, `.venv/` (`.gitignore`가 자동으로 걸러 줍니다)

## 2. 코드 요구사항 — 채점에 직결됩니다

1. **단위를 변수 이름에 표기**
   ```python
   m_kg = 1.0e5
   k_N_per_m = 4.0e6
   ```
2. **입력값 검증 `assert` 최소 1개**
   ```python
   assert 0.0 <= zeta < 1.0, f"zeta={zeta}: 저감쇠 범위가 아니다"
   ```
3. **결과를 화면에 출력** — 채점자가 실행해서 바로 볼 수 있어야 합니다
4. **가능하면 검증을 코드에 심을 것** — 이론해 vs 수치해, 또는 역산해서 입력값 복원
   ```python
   zeta_back = delta / np.sqrt(4*np.pi**2 + delta**2)   # 대수감쇠율로 역산
   print(f"역산 zeta = {zeta_back:.4f} (입력 {zeta:.4f})")
   ```
5. **다른 사람 컴퓨터에서 돌아갈 것** — 절대경로 금지
   ```python
   plt.savefig("figs/response.png")          # ✓
   plt.savefig(r"C:\Users\홍길동\바탕화면\a.png")  # ✗
   ```

## 3. 과제 README.md 양식

각 `hwN/` 폴더에 이 양식으로 `README.md`를 넣으세요.

```markdown
# HW1 — SDOF 감쇠 자유진동

**학번/이름:** 32251234 홍길동
**실행 방법:** `python hw1.py`

## 1. 문제 조건
| 항목 | 값 | 단위 |
| --- | --- | --- |
| 질량 m | 1.0e5 | kg |
| 강성 k | 4.0e6 | N/m |
| 감쇠비 ζ | 0.05 | - |
| 초기변위 x₀ | 0.02 | m |

## 2. 방법
- 저감쇠 해석해 x(t) = e^(-ζωₙt)[x₀cos(ω_d t) + ((v₀+ζωₙx₀)/ω_d)sin(ω_d t)]
- 검증: 연속 피크 2개로 대수감쇠율 δ 계산 → ζ 역산 → 입력값과 비교

## 3. 결과
| 항목 | 값 |
| --- | --- |
| ωₙ | 6.3246 rad/s |
| Tₙ | 0.9935 s |
| 역산 ζ | 0.050003 (입력 0.05, 상대오차 0.006%) |

![응답](figs/response.png)

## 4. 고찰
(2~5문장. 결과가 물리적으로 타당한 이유, 또는 예상과 달랐던 점)

## 5. AI 사용 내역
- Copilot Chat: Newmark-β 구현 골격 요청 → 이론해와 비교해 오차 0.1% 확인 후 채택
- 직접 판단한 부분: 시간간격 dt = Tₙ/200 결정, assert 조건 설정
```

## 4. AI 사용 정책 — 읽고 따르세요

**AI 사용은 허용이 아니라 권장입니다.** 다만 조건이 있습니다.

| 허용 | 금지 |
| --- | --- |
| 코드 작성·디버깅을 AI에게 맡기기 | 문제 전체를 AI에게 던지고 결과만 붙여넣기 |
| 개념 설명을 AI에게 묻기 | **AI가 낸 숫자를 검산 없이 제출** |
| AI가 쓴 코드를 이해한 뒤 채택 | AI가 인용한 기준 조항을 확인 없이 인용 |

**필수:** README에 **AI 사용 내역**을 적으세요. 무엇을 시켰고, 무엇을 본인이 판단했는지.
숨기는 것이 감점이지, 쓰는 것은 감점이 아닙니다.

**구두 확인:** 제출 코드에 대해 "이 줄이 왜 필요한가"를 물었을 때 설명하지 못하면
그 부분은 점수에 반영되지 않습니다. **이해한 만큼만 제출하세요.**

## 5. 채점 기준 (100점)

| 항목 | 배점 | 만점 조건 |
| --- | --- | --- |
| **정확성** | 40 | 이론적으로 옳고, 실행하면 실제로 그 결과가 나옴 |
| **검증** | 20 | 결과가 맞다는 **증거**가 코드 안에 있음 (역산·이론해 대조·수렴 확인 등) |
| **단위·방어코드** | 15 | 단위 표기 변수명 + assert. 단위 오류 발견 시 이 항목 0점 |
| **재현성** | 10 | clone 후 `python hwN.py` 한 번에 실행됨. 절대경로·수동조작 없음 |
| **Git 사용** | 10 | 커밋 2개 이상, 메시지가 내용을 설명함, 브랜치+PR 규칙 준수 |
| **고찰·문서** | 5 | README 양식 충족, AI 사용 내역 기재 |

### 감점 사유
| 사유 | 감점 |
| --- | --- |
| Push 안 함 (커밋만 함) | 미제출 처리 |
| `main`에 직접 push | -10 |
| 커밋이 1개뿐 ("완성" 한 방 커밋) | -5 |
| AI 사용 내역 미기재 | -5 |
| 다른 사람 폴더 수정 | -10 |

## 6. 제출 직전 최종 점검

- [ ] `python hwN.py` 를 **깨끗한 상태에서** 실행해 봤다 (VS Code 재시작 후)
- [ ] 결과 숫자가 README에 적은 값과 **일치한다**
- [ ] 그래프 PNG가 `figs/`에 실제로 저장되어 있다
- [ ] 브라우저에서 내 브랜치를 열어 **파일이 다 보인다** (= push 완료)
- [ ] PR을 만들었고 제목이 `[HW1] 학번 이름` 형식이다
- [ ] README에 AI 사용 내역이 있다
