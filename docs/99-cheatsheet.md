## 매일 반복하는 6단계

```
① Pull      작업 시작 전, 최신화        Source Control ⋯ → Pull
② 작업      코딩. Ctrl+S 자유롭게
③ +         커밋에 넣을 파일 선택        파일 이름 옆 + 버튼
④ 메시지    무엇을 왜 바꿨는지 한 줄
⑤ ✓ Commit  내 컴퓨터 이력에 도장
⑥ Push      서버에 반영  ← 여기까지 해야 끝
```

**Commit ≠ Push.** 브라우저에서 파일이 보여야 진짜 올라간 것입니다.

## 동역학 상수 — 자가 검산용

| 양 | 식 |
| --- | --- |
| 고유각진동수 | ωₙ = √(k/m) |
| 고유주기 | Tₙ = 2π/ωₙ |
| 임계감쇠계수 | c_cr = 2√(km) = 2mωₙ |
| 감쇠비 | ζ = c/c_cr |
| 감쇠고유진동수 | ω_d = ωₙ√(1−ζ²) |
| 대수감쇠율 | δ = ln(xᵢ/xᵢ₊₁) = 2πζ/√(1−ζ²) |
| 감쇠비 역산 | ζ = δ/√(4π² + δ²) |
| 동적증폭계수 | Rd = 1/√((1−r²)² + (2ζr)²),  r = ω/ωₙ |
| 공진 최대증폭 | Rd_max ≈ 1/(2ζ) (r ≈ 1) |

2. **식·조항은 출처 확인 전까지 가설이다.** 확인 못 하면 쓰지 않는다.
