# 00 — 왜 GitHub을 쓰는가

설치할 것 없습니다. 5분만 읽으세요. 용어가 잡히면 나머지는 클릭 몇 번입니다.

---

## 1. 한 줄 요약

**GitHub = 도면철의 개정 이력 관리 시스템을 코드·문서에 적용한 것.**

구조 설계에서 Rev.A → Rev.B → Rev.C를 전부 보관하고, 누가 언제 무엇을 왜 바꿨는지
남기고, 본사 도면철과 현장 사본을 맞추는 일. 그걸 파일 단위로 자동화한 것이 GitHub입니다.

## 2. 이걸 왜 수업에서 쓰나 — 실질 이유 4개

| 문제 | GitHub 없이 | GitHub 쓰면 |
| --- | --- | --- |
| 어제까지 되던 코드가 오늘 안 돌아감 | `과제_최종_진짜최종_v3.py` 뒤지기 | 어제 상태로 1클릭 복원 |
| 노트북 고장 / 파일 날림 | 처음부터 다시 | 서버에 그대로 남음 |
| 팀 과제에서 파일 주고받기 | 카톡으로 zip, 누구 게 최신인지 모름 | 항상 최신본 하나 |
| 제출한 과제가 안 열림 | 메일 재전송 요청 | 실행 이력·환경까지 같이 제출됨 |

여기에 하나 더. **학생 인증을 받으면 GitHub Copilot(코딩 AI)을 무료로 씁니다.**
이 수업에서 AI를 쓸 통로가 GitHub 계정이라, 가입이 첫 단계인 이유입니다.

## 3. 용어 6개 — 이것만 알면 됩니다

| 용어 | 뜻 | 도면 비유 |
| --- | --- | --- |
| **Repository** (레포지토리, repo) | 프로젝트 폴더 + 그 폴더의 전체 이력 | 도면철 한 권 |
| **Clone** (클론) | 서버의 레포를 내 컴퓨터로 통째 복사 | 본사 도면철 사본을 현장에 가져옴 |
| **Commit** (커밋) | "지금 이 상태를 한 묶음으로 저장" + 왜 바꿨는지 메모 | Rev 도장 찍고 개정란에 사유 기입 |
| **Push** (푸시) | 내 컴퓨터의 커밋들을 서버로 올림 | 현장 수정본을 본사 도면철에 반영 |
| **Pull** (풀) | 서버의 최신 상태를 내 컴퓨터로 내려받음 | 본사에서 최신 개정본 수령 |
| **Branch** (브랜치) | 본선과 분리된 작업 사본 | 검토용 별도 도면철 |

**초반 3주는 clone / commit / push / pull 네 개만 씁니다.** Branch는 팀 과제부터.

### 커밋과 저장(Ctrl+S)의 차이

| | Ctrl+S (저장) | Commit (커밋) |
| --- | --- | --- |
| 대상 | 파일 하나 | 관련된 변경 묶음 전체 |
| 이력 | 안 남음. 덮어씀 | 영구히 남음. 되돌리기 가능 |
| 메모 | 없음 | 필수 ("감쇠비 5%로 수정") |
| 빈도 | 수십 번/시간 | 1~5번/시간, 한 작업이 끝날 때 |

정리하면 **Ctrl+S는 연필 자국, Commit은 개정 도장**입니다.

## 4. 실제로 어떻게 흘러가나 — 하루 흐름

```
[아침] Pull          → 강의자료·팀원 수정본 최신화
   ↓
[작업] 코드 작성, Ctrl+S 수십 번, Copilot에게 질문
   ↓
[한 단락 끝] Commit  → "예제1: 감쇠 자유진동 이론해 구현"
   ↓
[또 한 단락] Commit  → "예제1: Newmark-β 수치해 추가, 이론해와 오차 0.2%"
   ↓
[끝날 때] Push       → 서버에 반영. 이제 어느 컴퓨터에서든 이어서 가능
```

## 5. 자주 나오는 오해 3개

**"코딩 잘하는 사람만 쓰는 거 아닌가요?"**
아닙니다. GitHub은 *파일 이력 관리* 도구입니다. 이 저장소의 문서도 전부 GitHub에서 관리됩니다.
엑셀 계산서, 보고서 초안, 회의록도 똑같이 올릴 수 있습니다.

**"실수로 지우면 어떡하죠?"**
커밋한 뒤라면 복구됩니다. GitHub의 존재 이유 자체가 그것입니다.
무서운 건 **커밋 안 한 상태**입니다. 그래서 자주 커밋하라고 하는 겁니다.

**"제 코드를 전 세계가 보나요?"**
아닙니다. 저장소는 **Private(비공개)** 로 만들 수 있고, 이 수업 저장소도 비공개입니다.
초대받은 사람만 봅니다. 나중에 포트폴리오로 쓰고 싶을 때 공개로 바꾸면 됩니다.
